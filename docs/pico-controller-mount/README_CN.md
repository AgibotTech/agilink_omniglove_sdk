# 手套上盖 PICO 手柄转接支架

本目录收录用于将 PICO 手柄安装到手套上盖的结构件，包括手背卡扣，以及区分左右手的盖板和手柄支架。

## 文件使用

- 盖板和手柄支架按同一手别配对。`images/` 和 `models/` 中对应的文件使用相同的零件编号与英文名称。
- 通过 JPEG 渲染图辨认外形；在支持 STEP AP214 的 CAD 软件中打开模型，查看几何并以毫米为单位测量尺寸。
- 加工或装配前，核对实际使用的手套上盖与 PICO 手柄的配合，并确认紧固件、材料和公差。
