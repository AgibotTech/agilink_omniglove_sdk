# PICO controller mount for the glove top cover

This folder contains the mechanical parts for mounting a PICO controller to
the glove top cover. It includes a glove-back clip and separate left- and
right-hand cover plates and controller brackets.

## Selecting and opening files

- Pair the cover plate and controller bracket for the same hand. The part
  number and English name match between `images/` and `models/`.
- Use the JPEG renderings to identify the parts. Open the STEP AP214 files in
  a CAD tool to inspect the geometry and measure dimensions in millimetres.
- Before fabrication or assembly, confirm fit with the intended glove top
  cover and PICO controller, and verify the fasteners, material, and tolerances.
