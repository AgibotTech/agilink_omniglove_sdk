# T1.5 触觉点位布局 v1

单手共 746 个有效触觉点，按以下 15 个子区域读取。DIRECT、UDP 和 ROS 2
使用相同的点位顺序；每个子区域的局部编号独立从 1 开始。
左右手的区域点数和全局切片相同，二维点位分布按各自矩阵读取。

每个有效点的触觉值为 `uint8`，范围 `0..255`，单位 `1 g/LSB`：
数值 `n` 表示 `n g`。矩阵中的正整数是点位索引，不是触觉测量值。

## 读取规则

- 矩阵按行从上到下、列从左到右展开；矩阵外框为 `rows × columns`。
- 矩阵中的 `0` 表示没有传感器，读取时跳过；有效传感器的触觉值为 `0` 时仍是有效点。
- 正整数 `k` 是当前子区域的 1-based 局部编号，对应读取该区域 `data[k-1]`。
  输出数组仅包含有效点，长度为 `count`，不会为矩阵空位增加字节。
- `rows × columns` 是矩阵格数，`count` 是有效点数，两者可能不同。
  例如 `thumb.tip` 的矩阵有 56 格，输出 `data` 长度为 38；
  `palm.surface` 的矩阵有 600 格，输出长度为 308。
- 全局切片 `[a,b)` 为 0-based 半开区间。局部编号 `k` 的全局索引为 `i=a+k-1`。
  POSE mode 1 的 `tac_pos.points[i]` 与该触觉点配对，XYZ 为腕坐标系下的米制位置。
- 按样本的 `hand` 选择左手或右手矩阵；点位位置使用该手已列出的编号，不自行镜像或重排数组。

例如，`index.pad` 的局部编号 1 对应 `index.pad.data[0]`、全局触觉索引 104，
以及 POSE mode 1 的 `tac_pos.points[104]`；该区域局部编号 28 对应全局索引 131。

区域对象、输出格式和未映射数据的读取规则见
[DIRECT / UDP 数据格式](./STREAM_DATA_V1.md)。
下表区域路径使用 UDP 名称；DIRECT / ROS 2 中手掌区域字段为 `tactile.palm_surface`，
其余区域按 `tactile.<finger>.<region>` 读取。表内 15 个子区域均非空；
公开结构中的其他区域槽位保持为空。

左右手掌面的物理位置见 [触觉点位映射图片](./TACTILE_POINT_MAPPING_IMAGES.md)。
